```
7datawin-main/
├── app/
│   └── frontend/              # React 19 + Vite 8 + Tailwind 4
│       ├── src/

│       │   ├── main.jsx       # Entry point
│       │   ├── index.css      # Global styles
│       │   ├── components/    # Navbar, Footer, HeroBanner

│       ├── public/            # Images, icons
│       ├── vercel.json        # Vercel SPA config

├── DeepTutor/                 # AI Backend (DeepSeek v4)
│   ├── deeptutor/
│   │   ├── api/               # FastAPI server (port 8001)
│   │   ├── agents/            # AI agents (chat, solve, research, etc.)
│   │   ├── tutorbot/          # Multi-channel bot framework
│   │   └── services/          # LLM, RAG, embedding services
│   ├── web/                   # Next.js web UI
│   └── pyproject.toml         # Python dependencies
└── AI_Academy_Somali/         # 30+ Somali courses + RAG KB
    ├── koorsooyinka/          # 5 qaybood oo koorsooyin ah
    └── knowledge_base/        # RAG knowledge base
```

## 🚀 Sida Loo Isticmaalo

### Frontend (React/Vite)

```bash
cd app/frontend
npm install --legacy-peer-deps
npm run dev
# → http://localhost:5173
```

### Backend (DeepTutor API)

```bash
cd DeepTutor
uv run uvicorn deeptutor.api.main:app --host 0.0.0.0 --port 8001
# → http://localhost:8001/docs
```

### Deploy Vercel

```bash
cd app/frontend
vercel --prod
```
