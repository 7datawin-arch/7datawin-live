# 🚀 7datawin - The Ultimate Data Selling App

Ku soo dhawaow **7datawin**! Waa barnaamij (App) casri ah oo loogu talagalay in lagu iibiyo xirmooyinka internet-ka (Data) qiimo jaban oo ku habboon dadka danyarta ah. 📱💸

Mashruucan waxaa si gaar ah loogu habeeyay suuqa Geeska Afrika (**Somaaliya 🇸🇴, Somaliland 🇸🇴, Ethiopia 🇪🇹, Kenya 🇰🇪, Jabuuti 🇩🇯**) isagoo taageeraya shirkadaha isgaarsiinta ee ugu waaweyn!

---

## ✨ Features-ka Cusub (Waxyaabaha Lagu Kordhiyay)

Waxaan ku kordhinay barnaamijka astaamo cusub oo casri ah oo kor u qaadaya bilicda iyo shaqada app-ka:

### 1. 🌍 Dynamic Localization & Geolocation
App-ku wuxuu hadda si toos ah u garanayaa dalka uu isticmaalaha ka soo galayo (isagoo isticmaalaya IP detection):
*   **🇸🇴 Soomaaliya:** Waxay si toos ah u muujisaa bogga Soomaaliya oo leh animations u eg mowjadaha badweynta buluugga ah (Rolling waves).
*   **🇰🇪 Kenya:** Waxay muujisaa sawirada iyo animations-ka u gaarka ah Kenya sida iftiinka cadceedda Savannah.
*   **🇪🇹 Itoobiya:** Waxay muujisaa buuraha iyo saameynta cagaarka & dharabka (Mist/Green particles).
*   **🇩🇯 Jabuuti:** Waxay leedahay animations digital ah oo u taagan isku-xirka Geeska Afrika.
*   **📍 Country Simulator:** Qeyb yar oo midigta sare ku taal oo aad ka dooran karto wadan kasta si aad u tijaabiso (ku habboon Localhost testing).

### 2. 📚 Akaadeemiyada Koorsooyinka (Courses Redesign)
Bogga Koorsooyinka waa la naqshadeeyay gebi ahaanba si uu u qaado **25 koorsooyin cusub** oo bilaash ah:
*   **🔍 Live Search Bar:** Waxaad ku dhex raadin kartaa koorsooyinka oo dhan magac ama qoraal ahaan.
*   **📁 5 Qaybood oo Abaabulan (Level-1 Accordion):** Koorsooyinka waxay u qaybsan yihiin kooxo:
    *   `AI & Teknolojiyadda` (ChatGPT, Web Dev, Cybersecurity, Word, PowerPoint...)
    *   `Suuqgeynta & Baraha Bulshada` (Digital Marketing, Facebook, TikTok, SEO...)
    *   `Naqshadaynta & Hal-abuurka` (Canva Design, Video Editing...)
    *   `Ganacsiga & Career-ka` (Freelancing, E-commerce, Sales, CV...)
    *   `Luuqadaha & Horumarka Qofka` (English, Somali Language, Public Speaking...)
*   **🔽 Syllabus Details (Level-2 Accordion):** Koorso kasta waxay leedahay badhan aad gujiso si aad u aragto cutubyada iyo casharrada rasmiga ah ee lagu baranayo.

### 3. ➕ Iibso Data - Labo Lambar (Multi-Number Support)
Hadda waxaa suurtagal ah in hal mar la iibsado data labo telefoon oo kala duwan loogu shubo (tusaale ahaan mid Hormuud ah iyo mid Somtel ah):
*   **Toggle Checkbox:** Marka la gujiyo `Ku dar Telefoon Labaad`, waxaa kuu furmaya form labaad oo aad ku qori karto lambarka iyo shirkadda labaad.
*   **Receipt Success UI:** Marka dalabka la xaqiijiyo, wuxuu kuu tusayaa rasiidh aad u qurux badan oo faahfaahsan oo muujinaya labada dalab iyo xirmooyinkooda.

## 🛠️ Technologies Used (Farsamada la isticmaalay)

- **Frontend:** React.js ⚛️ (Vite configuration)
- **Styling:** Tailwind CSS v4 🖌️ (leh custom CSS keyframes loogu talagalay animations-ka)
- **Icons:** Lucide React 🖼️
- **Routing:** React Router DOM 🛣️

## 🚀 Sida loo daarto (Local Development)

Si aad ugu shaqeyso mashiinkaaga (Local), raac talaabooyinkan:

1.  **Gal galka frontend-ka:**
    ```bash
    cd app/frontend
    ```
2.  **Soo deji baakadaha (Install dependencies):**
    ```bash
    npm install --legacy-peer-deps
    ```
3.  **Daaran App-ka:**
    ```bash
    npm run dev
    ```

App-ku wuxuu ka furmi doonaa `http://localhost:5173` 🌐

## 🌍 Vercel Deployment (Sida loogu xiro Vercel)

1.  Ku shub code-kan **GitHub**.
2.  Gal **Vercel** oo samee **New Project**.
3.  Dooro kaydkaaga (Repository) ee GitHub.
4.  **MUHIIM:** Qeybta `Root Directory`, ka dooro galka `app/frontend` (maxaa yeelay React-gu halkaas ayuu ku jiraa).
5.  Guji **Deploy** 🚀
